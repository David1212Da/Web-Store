# OFF/SCRIPT storefront

This folder contains the complete static website and its image files.

## Open it in VS Code

1. In VS Code, choose **File → Open Folder…** and select this `offscript-store` folder.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and select **Open with Live Server**.

## What's inside

- `index.html`, `styles.css`, and `script.js` are the storefront.
- `assets/` contains the images used by the page.
- `reference-materials/` contains all 14 original supplied images, including duplicates and the image not used in the storefront.
- The Fit Lab shuffles curated three-piece outfit ideas from the catalog.

Product names, sample prices, and sample sizes are in `script.js`. Replace these with your current stock details. To enable order handoff, set `STORE_WHATSAPP` near the top of `script.js` to your shop's international phone number using digits only. The newsletter form is a front-end demo and needs an email service to collect signups.
